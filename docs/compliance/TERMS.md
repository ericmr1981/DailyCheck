# 服务条款（草案）

> ⚠️ 状态：商业化前须由法律专业人士复核；定价/订阅细节见计费模块立项时补充。

## 1. 服务说明

DailyCheck 为客户提供多仓库库存管理软件服务（Web + AI Agent MCP 接口）。
具体功能范围以订单/合同附明的版本为准。

## 2. 账号与使用规范

- 客户应妥善保管账号凭据；经账号发起的操作视为客户行为。
- 禁止：逆向工程、批量抓取超出正常业务需要的数据、将服务转售给未授权第三方、
  利用系统漏洞获取未授权数据（漏洞请按 SECURITY.md 报告）。

## 3. 数据

- 客户数据的所有权归客户；客户授权部署方为提供服务之目的存储和处理该数据。
- 服务终止后，客户可申请在约定期限内导出数据，逾期部署方有权删除。

## 4. 服务水平

见 `docs/compliance/SLA.md`。因客户自身网络、第三方 AI Agent 客户端、
不可抗力导致的不可用不计入停机时间。

## 5. 责任限制

在法律允许的最大范围内，部署方对间接损失（利润损失、业务中断等）不承担责任；
累计责任上限为客户在索赔发生前 12 个月内支付的服务费总额。

## 6. 条款变更

重大变更将提前 30 天通知；继续使用视为接受。
