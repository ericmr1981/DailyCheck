# 页面设计提示词：角色列表

> 页面：`/admin/permissions`（Tab 2 = 角色列表）｜ 阶段 2 ｜ 设计师：颜好看
> 依赖：`design-tokens.css` · `design-system/pages/permissions.md`

## 路由与可见性

- 路由：`/admin/permissions?tab=roles`。
- 可见性：仅 `is_admin`。

## 布局

```
[Tab 条]  权限矩阵 | 角色列表
[工具栏]  搜索角色 · [新建角色 (二期·禁用)]
[表格]    角色名 | 类型 | 成员数 | 权限点数 | 操作[查看权限]
[说明]    staff 仅录入 · manager 可审批/删除单据 · admin 该仓全权
[抽屉]    480px 右侧滑入（点"查看权限"）
```

- 表格容器复刻 `.users-table-wrap` 规格：`--panel` + 1px `--border` + `--radius-lg`。
- 行 hover `--border-soft` 底；整行可点（打开抽屉），`cursor:pointer`。

## 核心组件

| 列 | 内容 | 说明 |
|----|------|------|
| 角色名 | 中文名 + `.role-tag--<code>`（见 MASTER 角色标签系统） | 例：`基础作业` + `.role-tag--staff` |
| 类型 | 中性 chip「内置」/「系统」 | 不用彩色，避免彩虹 |
| 成员数 | 来自 `warehouse_users` 聚合（**真实数据**） | 平台管理员显示「—」（不进绑定） |
| 权限点数 | 该包权限点数（staff 10 / manager 16 / admin 19 / viewer 3 / finance 4） | 从 manifest 计算 |
| 操作 | 文字按钮「查看权限」 | 打开 480px 抽屉 |

### 行清单（6 行，数据契约）

| 角色名 | tag 类 | 类型 | 权限点数 |
|--------|--------|------|----------|
| 基础作业 | `--staff` | 内置 | 10 |
| 管理审批 | `--manager` | 内置 | 16 |
| 仓管理 | `--admin` | 内置 | 19 |
| 只读/审计 | `--viewer` | 内置 | 3 |
| 财务 | `--finance` | 内置 | 4 |
| 平台管理员 | `--super` | 系统 | —（bypass 全部，不进包） |

## 交互

| 操作 | 反馈 |
|------|------|
| 点击行 / 「查看权限」 | 打开右侧 480px 抽屉，标题=角色中文名 + tag |
| 搜索角色 | 实时过滤（中文名 / code） |
| 悬停「新建角色」 | tooltip「自定义角色为二期功能」；按钮 `disabled` |
| 键盘 | 行可 Tab 聚焦，Enter 打开抽屉；Esc 关闭抽屉并回焦触发元素 |

## 抽屉内容（角色权限清单）

```
┌ 基础作业 [.role-tag--staff]                    [x] ┐
├ 说明：仅录入，不含审批/删除/成本可见                │
├ ▾ 订货                                             │
│   下单 order.create        [已授予]                │
│   收货 order.receive       [已授予]                │
├ ▾ 库存                                             │
│   出库 stock.outbound      [已授予]   …            │
├ ▾ 品项  ▸ 报表  ▸ 管理                             │
├ 小计：已授予 10 项                                 │
└────────────────────────────────────────────────────┘
```

- 复用矩阵的域分组视觉（图标 + 中性 chip）与 dot-notation 等宽副标，保持连续性。
- 仅列**已授予**项（未授予不展示，减少噪音）；或在域头标注「已授予 x / 共 y」。
- 只读，无勾选框（避免"看起来能改"的误导）。

## 响应式

- ≥768px：右侧 480px 抽屉。
- <768px：<768 用**底部 ActionSheet**（自下而上滑入，最大高 85vh），符合移动端惯例。

## 5 态

| 态 | 表现 |
|----|------|
| Loading | 表格骨架行 |
| Empty | 「暂无角色」+ 说明（理论不空，5 内置恒在） |
| Error | 「角色数据加载失败」+ 重试 |
| Populated | 6 行 |
| Edge | 角色名超长 → ellipsis + title；成员数极大 → 千分位分隔 |
