# 隐私政策（草案）

> ⚠️ 状态：商业化前须由法律专业人士复核。本稿基于系统实际数据处理现状撰写。
> 生效日期：未生效（商业化上线时确定）

## 1. 我们处理的信息

DailyCheck 是库存管理系统，处理的数据包括：

| 数据 | 用途 | 存储 |
|------|------|------|
| 账号信息（用户名、密码哈希） | 登录鉴权 | master.db（部署方自有服务器） |
| 仓库/品项/库存/订单等业务数据 | 核心功能 | 每仓独立 SQLite 文件 |
| 登录失败记录（IP + 用户名） | 防暴力破解，30 分钟锁定窗口 | master.db login_throttle |
| MCP 访问日志（token、操作） | 审计 | master.db access_log / audit_log |

- **密码只存 pbkdf2 哈希**，任何人（包括管理员）不可还原。
- 系统不接入第三方统计/广告 SDK，**不做用户行为追踪**。

## 2. 数据归属与位置

- 所有数据存储在**部署方自有服务器**（当前：单台 VPS），不经过第三方云。
- 备份保留在部署方服务器备份目录；异地备份（对象存储）引入时此处将更新。

## 3. 你的权利

- 导出：联系管理员导出你的业务数据（结构化 JSON/CSV）。
- 删除：账号删除请联系管理员（关联业务数据按业务保留规则处理）。
