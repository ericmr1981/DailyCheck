# 门店订货 v3.1 用户操作流程

- 日期：2026-10-06
- 关联：feat/store-ordering 分支
- 新增功能：A. 品项可订开关  /  B. 运费规则（基础运费 + 金额百分比服务费）

---

## A. 品项可订开关

### 谁用

| 角色 | 能做什么 |
|---|---|
| 平台 admin | 任何 DC 的任何品项开关 |
| DC manager / DC admin | 自己绑定 DC 的品项开关 |
| DC staff | **不能**（@require_role("manager")） |
| 门店 staff / manager / admin | **不能**（只读侧：catalog 过滤生效） |

### 入口

`/store-ordering/dc/items` —— DC 区导航新增「品项管理」。

### 操作步骤（DC manager / admin）

1. 进入「品项管理」页面，看到当前 DC 的所有品项列表（按品类分组）。
2. 每行显示：品项名 / 单位 / 当前库存 / 状态 pill（绿「可订」/ 灰「不可订」）/ 右侧切换按钮。
3. 点击切换按钮 → 即时生效，状态 pill 颜色翻转，flash「已切换为可订 / 已下架」。
4. 切回 catalog 端验证：已关闭品项从门店 catalog 列表消失（如果门店刷新页面）。

### 对门店用户的影响（只读）

| 场景 | 表现 |
|---|---|
| catalog 浏览 | `is_orderable=0` 的品项不出现在卡片列表 |
| 购物车里之前加过、之后被下架的品项 | 提交时被拦截，flash「以下品项已下架，请移除」并列出明细；订单不会创建 |
| 已下单订单里的被下架品项 | **不受影响**（订单是合同，开关只对未来生效） |
| DC 端 review / 出库界面 | 仍能看到所有订单品项（不区分开关） |

### 边界

- 切换不可订不影响 `items.quantity` —— 库存操作正常进行
- 一个品项在某个 DC 不可订，不影响其他 DC 是否可订
- 不影响 `canonical_items.status` —— 这是平台级品项状态，独立维度

## B. 运费规则

### 谁用

只有**平台 admin** 能配置。DC / 门店用户只读。

### 入口

`/store-ordering/admin/shipping` —— admin 区导航新增「运费规则」。

### 操作步骤（admin）

1. 进入「运费规则」页面，看到表单：
   - **基础运费**（元）：每单固定收，默认 0
   - **服务费比例**（%）：订单金额百分比，默认 0
   - **激活**：单选（启用 / 停用）
   - **实时示例**：`订单金额 ¥100 → 运费 ¥5.00 + ¥1.00 = ¥6.00`
2. 修改后点「保存」→ 立即对**新订单**生效；已存在订单运费锁定不变。
3. flash「运费规则已保存」。

### 公式（确认：方案 a 加和）

```
shipping_fee = base_fee + subtotal × pct_fee
```

### 对门店用户的影响

| 场景 | 表现 |
|---|---|
| 提交订单页（submit） | 底部新增「运费预估 ¥X」「总计 = 订单金额 ¥XX + 运费 ¥X = ¥YYY」 |
| 订单详情（order_detail，storefront 视角） | 信息卡新增「运费」行 + 「订单总计 = 订单金额 + 运费」行 |
| 订单历史（orders.html） | 列表暂不显示运费（明细在详情页） |

### 对 DC 端的影响

| 场景 | 表现 |
|---|---|
| 订单详情（order_detail，DC 视角） | 同样显示「运费」「订单总计」行 |
| 出库操作 | **不影响** —— 出库时锁定 shipping_fee，不重新算 |

### 取消订单时的运费

- 取消 pending 订单 → 运费作废（订单不产生，shipping_fee=0）
- 取消 approved 订单 → 运费作废（已 ship 不允许取消；未 ship 取消时 shipping_fee 归 0）
- 已 shipped / delivered 订单 → **不可取消**（不在取消路由覆盖范围）

### 修改规则后的影响

| 时间点 | 行为 |
|---|---|
| 已 ship 的订单 | 运费锁定不变（store_orders.shipping_fee 持久化） |
| 提交时（pending/approved 未 ship） | 实时按当前规则计算 |
| 取消重提交 | 重新计算 |

### 报表扩展（admin/report）

- 顶部 KPI 卡新增第 5 张「总运费」
- by_store / by_dc 维度表新增「运费」列
- 订单金额 + 运费 = 「订单总计」（业务侧理解）

## 用户操作速查表

| 操作 | 路径 | 谁能做 |
|---|---|---|
| 切换某品项可订状态 | `/store-ordering/dc/items` → 行按钮 | DC manager / admin |
| 配置运费规则 | `/store-ordering/admin/shipping` → 表单 | admin |
| 查看订单运费 | 任意订单详情页 → 信息卡 | 所有人（订单可见性规则） |
| 看总运费报表 | `/store-ordering/admin/report` | admin |
