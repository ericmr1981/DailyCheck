# 生产验证报告（Production Verification Report）

> **用途**：Prod Agent 拉 PR 后，在生产蓝绿环境跑一遍完整验证，出报告决定是否切流量。
> **触发**：每个 PR 进 prod 验证前必出。
> **门禁**：5 个检查项全绿 → 切流量；任一红 → 打回 PR，绿环境留作取证。

---

## 1. 元信息

| 字段 | 值 |
|------|-----|
| PR | #（链接） |
| 源 commit | `sha` |
| 蓝环境（线上） | version `v1.x.y`，监听 `0.0.0.0:8090` |
| 绿环境（候选） | version `pr-<num>-<sha>`，监听 `0.0.0.0:8091` |
| 主库 | 共享只读 + 绿环境 dry_run 写前缀 |
| Prod Agent | 标识 |
| 生成时间 | ISO8601 |

## 3. 写流量隔离证据

```
绿环境干 INSERT 日志: dry_run=true, target_table=green_<original>_
SQLite: SELECT * FROM sqlite_master WHERE name LIKE 'green_%'
       → 仅含 prod 表头（dry_run 未真正建表）

主库 production 表: SELECT count(*) FROM production
                  → 与蓝环境启动前一致（dry_run 隔离生效）
```
